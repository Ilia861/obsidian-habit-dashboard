# Obsidian Habit Dashboard

[English README](README.md) · [Русская справка](docs/ru/Help.md) · [Публикация](docs/PUBLISHING.md)

Локальный трекер привычек для Obsidian Desktop: **только Dataview**, SVG и CSS snippet. Русский и английский интерфейсы используют одну кодовую базу. Отдельный русификатор и дополнительные плагины графиков не нужны.

## Установка

Скачайте `habit-dashboard-v1.4.1.zip`: единый пакет с английским по умолчанию и встроенным русским. Распакуйте содержимое в хранилище Obsidian (Obsidian Vault), включая скрытую папку `.obsidian`, включите JavaScript Queries в Dataview и snippet `habit-dashboard`, откройте `Habit Dashboard/Dashboard.md`. Для русского интерфейса задайте `language: ru`. Внутри есть инструкции, обе справки, 3 календаря и 1 числовая привычка с примерами.

Автоматический GitHub-архив **Source code** предназначен для разработки; сначала выполните сборку командами ниже.

## Язык без изменения истории

```yaml
language: en
date_format: "YYYY-MM-DD"
habits_folder: "Habits"
cssclasses:
  - habit-dashboard-page
```

Для смены интерфейса меняйте только `language`. **Сохраните прежние habits_folder и date_format.** Русская установка продолжает читать `Привычки`, английская — `Habits`. Смена языка не переименовывает файлы, не переводит личные названия/единицы и не меняет историю. Оба раздела `## Журнал` и `## Journal` поддерживаются при любом языке. YAML-ключи и формат записей прежние: даты ISO, числа с точкой.

Для обновления сделайте резервную копию и замените дашборд, `Help.ru.md`, `Help.en.md` и CSS. Перенесите свои свойства дашборда и сохраните личные журналы. Не распаковывайте демонстрации поверх них. Миграция данных не требуется.

## Возможности

- Адаптивные календари в 3/2/1 колонку, цвета темы и отступы только для дашборда.
- Клик на дату: Сделал, Не сделал, Отмена. Дубли видимы с ИЛИ и диагностикой; вручную нужно исправить только саму дублированную дату для её редактирования.
- Кнопка числовой записи с датой, неотрицательным количеством, дробями и нулём. Повторные даты добавляют отдельные строки и суммируются; график на клик/тап не реагирует.
- По дням, накопительно за месяц, среднее за 7 календарных дней. Нет записи — разрыв; явный ноль — наблюдение. Высота графика 190 px, шрифт шкалы 11 px не масштабируются с шириной.
- Серии, уникальные выполнения и суммы; текущие/общие показатели не зависят от выбранного исторического месяца.
- Месяцы ограничены самым ранним корректным стартом и текущим месяцем.
- Обновление после записи без служебных надписей, соседние строки журнала, защита от параллельных правок и ссылка на исходник.

## Разработка и сборка

Для разработки нужен Node.js **22 или новее**, для работы в Obsidian он не нужен. **Зависимостей npm нет**, установка пакетов не требуется.

```sh
npm run validate:locales
npm test
npm run build
```

Тестовая команда проверяет переводы, единый пакет и совместимость со старой русской установкой. `npm run build` собирает только пакет с английским по умолчанию. В `dist/` находятся один установочный ZIP, SHA256, заметки релиза и распакованный комплект `en/`. Тесты дополнительно создают `ru/` только как внутреннюю фикстуру совместимости, без второго ZIP. `dist/BUILD.json` (вне установочного ZIP) содержит хеш общего кода. Сборка воспроизводима и использует встроенные средства Node.

Структура: общий код в `src/`, переводы в `locales/`, единая история демонстраций в `examples/`, проверки в `tests/`, команды в `scripts/`, шаблоны документации в `docs/ru/` и `docs/en/`. Значения `{{...}}` заменяются при сборке на реальные пути и версию.

## GitHub

Одна общая ветка `main`, временные ветки для доработок, без отдельных постоянных ru/en. CI проверяет Node 22/24 и прикладывает один установочный ZIP. Тег, совпадающий с версией package.json, например `v1.4.1`, создаёт **черновик** релиза с единым пакетом и контрольными суммами. Подробности — в [инструкции публикации](docs/PUBLISHING.md).
