# Приёмочные проверки — {{version}}

Автоматические тесты и проверки переводов/сборки находятся в исходном репозитории. Имитация браузера не подтверждает работу реального API Obsidian. Проверяйте на копии Vault.

- Включить Dataview, JavaScript Queries и CSS. Открыть `{{folder}}/{{dashboardName}}`: 3 календаря и 1 график.
- Менять language между ru/en, сохраняя habits_folder/date_format. Проверить подписи, диагностику, окна, дни недели/месяцы, числа и справку. Имена привычек, единицы и исходные файлы не должны изменяться.
- Открыть сразу после установки/обновления индекса. При недоступной текущей заметке используется известный путь контекста; без пути — понятное сообщение, без подстановки активной чужой заметки.
- «Предыдущий» останавливается на самом раннем корректном старте, «Следующий» — на текущем месяце. Добавить/удалить старую привычку и проверить индексацию границ.
- Сделал/Не сделал меняет одно значение; новая дата добавляет соседнюю строку. Отмена/Escape и ссылка на файл не записывают данные. Будущие/до-стартовые дни отключены.
- Бинарные дубли остаются видимыми с ИЛИ и диагностикой; дата считается один раз. Заблокировано только изменение самой дублированной даты. Числовые дубли суммируются.
- Добавить 5, 5 и 20 за одну дату: три строки и сумма 30. Проверить ноль, точку/запятую, ограничения, выбор даты, ссылки, все режимы. Тап/клик на графике ничего не открывает.
- Обновление только после записи, без надписей и скачков. Параллельные правки, двойной клик, перемещение файла и ошибка записи не перезаписывают историю.
- Оба заголовка Journal/Журнал редактируются при обоих языках. Старые заголовки, комментарии и переносы остаются; новый журнал — на текущем языке.
- Светлая/тёмная тема, узкая панель, клавиатура, сенсорный ввод, фокус окна, 3/2/1 колонки, график на всю ширину высотой 190 px со шрифтом 11 px.
- Работа без сети и реальное обновление индекса после редактирования/переоткрытия заметки.
