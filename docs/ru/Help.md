# Помощь — Habit Dashboard {{version}}

## Смена языка

**English interface:** set `language: en` in the properties of `{{dashboardName}}`.

[Открыть дашборд]({{dashboardName}})

Файлы привычек можно переименовывать, в том числе давать им русские названия, например `Чтение.md`, внутри `{{folder}}/{{habitsFolder}}/`. Название карточки задаёт поле **`habit_name`** (например, `habit_name: Чтение`); одно лишь переименование файла его не меняет. Поле **`habit_id`** оставляйте прежним: это постоянный идентификатор. Смена языка интерфейса не переводит названия и единицы автоматически. Поле `unit` задаёт подпись единицы числовой привычки.

## Добавить привычку

1. Создайте Markdown-файл в `{{folder}}/{{habitsFolder}}/`.
2. Скопируйте шаблон ниже и задайте уникальный `habit_id`.
3. Заполните название, тип, дату старта и целое число порядка. Сохраните файл и дождитесь индексации Dataview.

Бинарная привычка:

```markdown
---
habit_id: swimming
habit_name: Плавание
habit_type: boolean
start_date: 2026-11-01
order: 5
---

## Журнал

- [date:: 2026-11-01] [value:: true]
- [date:: 2026-11-02] [value:: false]
```

Числовая привычка:

```markdown
---
habit_id: books
habit_name: Чтение книг
habit_type: number
unit: страниц
start_date: 2026-11-01
order: 10
---

## Журнал

- [date:: 2026-11-01] [value:: 15]
- [date:: 2026-11-02] [value:: 2.5]
- [date:: 2026-11-03] [value:: 0]
```

Одна пара date/value — в одном пункте списка, на одной строке. Реальные записи размещайте вне блока кода. Даты в файлах всегда `YYYY-MM-DD`, дроби — с точкой. Значения `true` и `false` пишите без кавычек, строчными буквами. Числа должны быть конечными и неотрицательными.

| Поле | Обязательно | Назначение |
|---|---|---|
| `habit_id` | Да | Уникальная непустая строка |
| `habit_name` | Да | Название карточки; его изменение не меняет историю |
| `habit_type` | Да | `boolean` или `number` |
| `start_date` | Да | Первый день отслеживания, например `2026-11-01` |
| `order` | Да | Целое число; меньшие значения выше |
| `unit` | Для number | Непустая единица измерения, например `страниц` |

Читаются только файлы непосредственно в папке привычек. Сначала идут календари, затем графики. Внутри группы сортировка по order, названию и пути файла. Название карточки открывает исходную заметку. Переименовывайте файлы средствами Obsidian. Перед удалением сделайте резервную копию; удалите файл или перенесите за пределы настроенной папки, чтобы убрать карточку.

## Язык, даты и папка данных

Настройки в свойствах дашборда (в существующем YAML-блоке):

```yaml
language: ru
date_format: "DD:MM:YYYY"
habits_folder: "{{habitsFolder}}"
cssclasses:
  - habit-dashboard-page
```

`language: ru` или `language: en` меняет интерфейс, сообщения и ссылку справки. Названия привычек и единицы измерения — ваши данные, они не переводятся автоматически. Файлы не переименовываются и не изменяются. **При смене языка сохраните прежние habits_folder и date_format.** Папка задаётся относительно заметки дашборда и не зависит от языка. В пути используйте `/`, без ведущего слеша, обратных слешей, пустых частей и `.` / `..`. Если поле отсутствует, единый пакет использует `Habits`, независимо от языка. При обновлении старой русской установки явно сохраните `habits_folder: "Привычки"`.

`date_format` не зависит от языка. Примеры: `DD:MM:YYYY`, `DD.MM.YYYY`, `DD/MM/YYYY`, `YYYY-MM-DD` или другой порядок трёх обозначений с одинаковым разделителем `: . / -`. Регистр важен; каждое обозначение используется один раз. При неверной настройке появляется предупреждение и ISO-формат отображения. Даты в файлах не меняются. Подписи чисел следуют языку интерфейса, числа в файлах всегда сохраняются с точкой.

Редактор понимает и `## Журнал`, и `## Journal` при любом языке. Существующие заголовки сохраняются; новый раздел создаётся на текущем языке. Два раздела журнала в одном файле неоднозначны и требуют ручного исправления. В комплекте ровно две справки: `Help.ru.md` и `Help.en.md`. Дашборд открывает справку на языке интерфейса.

## Отметить день календаря

Нажмите дату и выберите **Сделал**, **Не сделал** или **Отмена**. Доступны сегодня и прошлые дни от старта привычки. Будущие и до-стартовые дни отключены. Escape отменяет ввод. Ссылка **Открыть файл привычки** открывает исходник в новой вкладке, ничего не сохраняя.

Существующая запись меняет только boolean-значение; новая дата добавляет компактную строку списка. Старые комментарии, пробелы и история не переформатируются. Просмотр и отмена ничего не записывают. Ячейка меняется только после успешной записи, без ожидания Dataview и без служебных надписей. Если она не изменилась, проверьте файл вручную. Пока идёт запись, повторный ввод этой привычки заблокирован.

Дубли бинарных дат не скрывают календарь: диагностика раскрывается и показывает номера строк. Отображение и статистика используют **ИЛИ**: любое true означает выполненный день; дата считается один раз. Изменять через окно саму дублированную дату нельзя, пока вручную не оставлена одна запись; другие дни доступны. Автоматического удаления дублей нет.

## Добавить числовую запись

Нажмите **Добавить запись** в карточке. Клик или тап по графику ничего не открывает. Дата по умолчанию — сегодня, даже при просмотре другого месяца. Количество изначально пустое, рядом показана единица измерения. Разрешены ноль и неотрицательные дроби с точкой или запятой: `5`, `0`, `2.5`, `2,5`. Будущие и до-стартовые даты недоступны. Календарь выбора может использовать системный формат; ниже показана дата в вашем date_format.

Подсказка показывает старый итог, добавление и новый итог за день. **Добавить** или Enter в количестве всегда создаёт новую строку; Отмена/Escape ничего не пишет. Добавления 5, 5 и 20 дают три записи и сумму 30. В любом режиме графика вводится отдельный вклад, а не замена итога или среднего. Ошибочную строку исправляйте вручную в исходном файле.

График и статистика меняются после успешной записи. Выбранные месяц и режим сохраняются. Если дата вне выбранного месяца, переключитесь на её месяц. Надписей, сдвигающих карточки, нет. Параллельные изменения, перемещение файла или неоднозначный Markdown блокируют сохранение; проверьте файл и откройте окно заново.

## Читать дашборд

- «Предыдущий» останавливается на месяце самого раннего корректного start_date, «Следующий» — на текущем месяце. Пустой/некорректный набор и только будущие старты оставляют текущий месяц. Границы обновляются после индексации состава привычек.
- Акцентный ✓ — выполнено; × — пропуск; пунктир — сегодня ожидает; приглушённый текст — вне учёта. Сегодня обведено. Наведите указатель для даты и значения.
- Выполнение — true или суточная сумма больше нуля. Прошедший день без записи — пропуск. Сегодня без записи сохраняет серию до вчера; явный false/0 прерывает сразу. Текущие пропуски считают только завершённые дни; выполнение сегодня сбрасывает их.
- Максимальная серия и общие счётчики привязаны к фактическому сегодня, а не выбранному месяцу. Месячные счётчики считают уникальные даты. Числовые карточки также показывают суммы.
- По дням — суточные суммы. Явный ноль — точка на нуле; отсутствующая запись — разрыв.
- Накопительно — сумма с начала месяца. Отсутствующие наблюдения остаются разрывами, следующие точки включают прежние значения.
- Среднее за 7 дней — текущая дата и шесть предыдущих, включая прошлый месяц. Отсутствие и дни до старта дают нулевой вклад; делитель всегда 7. В дату без записи точка не рисуется; явный ноль остаётся наблюдением с преобразованным средним.

Подписи округлены до двух знаков, расчёты используют точность JavaScript number. Высота графика 190 px, шрифт шкалы 11 px. Календари: 3 колонки от 628 px внутренней ширины, 2 от 408, ниже — 1. Боковые панели и масштаб влияют сильнее разрешения экрана. Класс заметки даёт отступы 32 px, не меняя другие заметки.

## Если что-то не работает

| Проблема | Что проверить |
|---|---|
| Нет карточки | Папку, YAML, обязательные поля, диагностику |
| Нет данных | Пару date/value в одной строке, ISO-дату, тип значения |
| Пустой график | Тип, месяц, дату старта, диагностику |
| Неверный вид | Включён ли CSS snippet habit-dashboard |
| Evaluation error | JavaScript Queries в Dataview; режим чтения или Live Preview |
| Не видны изменения | Индексацию, переоткрыть заметку; при необходимости перезапустить Obsidian |
| Повтор даты | По ссылке открыть файл и оставить одну boolean-запись вручную |
| Конфликт habit_id | Разные ID у файлов; истории никогда не объединяются |
| Сообщение об индексации при старте | Подождать и переоткрыть; путь другой активной вкладки не подставляется |

Неоднозначные записи автоматически не исправляются. Обновления не требуют переименования истории. Сделайте резервную копию Vault и заменяйте только интерфейс; не распаковывайте демонстрации поверх личных файлов.
