# Obsidian Habit Dashboard {{version}} — единый комплект

[English instructions](README.md)

1. Распакуйте содержимое ZIP в хранилище Obsidian (Obsidian Vault), включая скрытую папку `.obsidian`.
2. Включите плагин Dataview и **Enable JavaScript Queries** в его настройках. Другие плагины не нужны; работа не требует интернета.
3. Включите snippet `habit-dashboard`: Настройки → Оформление → CSS snippets. Если папка настроек Vault называется иначе, перенесите CSS в её подпапку `snippets`.
4. Откройте `{{folder}}/{{dashboardName}}` в режиме чтения или Live Preview.
5. Ссылка Help (после переключения языка — «Помощь») ведёт к инструкции. В комплекте три календаря и числовая привычка. Примеры относятся к октябрю–ноябрю 2026; при необходимости выберите ноябрь 2026.

Комплект готов к работе: редактирование JavaScript, npm, отдельный русификатор, Node.js и интернет внутри Obsidian не нужны.

## Сменить язык без переноса истории

Сохраните `habits_folder: "{{habitsFolder}}"` и свой date_format; для русского интерфейса поменяйте только `language: en` на `language: ru` (обратно — `language: en`). Оба перевода и обе справки уже внутри. Названия привычек, единицы, пути, YAML-поля и история остаются прежними. Формат дат не зависит от языка.

## Обновить существующий комплект

Сделайте резервную копию Vault. Замените существующую заметку дашборда новой версией и скопируйте `Help.ru.md`, `Help.en.md` и `.obsidian/snippets/habit-dashboard.css`. Перенесите свои свойства, особенно habits_folder, date_format и language. Для существующей русской установки сохраните `habits_folder: "Привычки"`; не переключайте её на папку английских демонстраций. Старое имя файла дашборда можно оставить. Выключите/включите snippet и переоткройте заметку.

**Не заменяйте личную папку привычек демонстрационными файлами.** Пакет один: английский по умолчанию, оба языка уже включены. В существующем Vault меняйте язык свойством и сохраняйте старую папку данных.

Исходники, автоматические тесты и инструкции сборки находятся в репозитории/архиве исходников проекта. Проверки в настоящем Obsidian описаны в `docs/ru/TESTING.md` и `docs/en/TESTING.md` в исходниках; служебные сведения сборки не входят в установочный пакет.

Старый дубликат `Habit Dashboard/Help.md` больше не используется: его можно удалить, проверив личные ссылки на него. Оставьте `Help.en.md` и `Help.ru.md`.
